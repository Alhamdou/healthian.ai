# healthian.ai
personal mobile app for my final year project 

Healthian.ai is an innovative healthcare application that aims to revolutionize the way people access and receive healthcare services. It combines advanced technologies and user-friendly features to provide a seamless and convenient healthcare experience. With Healthian.ai, users can easily search for doctors, find medicines, book appointments, and even have video consultations with healthcare professionals. The application focuses on empowering individuals to take control of their well-being by providing accessible, personalized, and virtual healthcare solutions. Its user-centric approach and cutting-edge features make it a game-changer in the healthcare industry
